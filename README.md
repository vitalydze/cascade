# cascade-vpn

Каскадный VPN из двух серверов:

```
телефон / ноутбук --WireGuard--> RU-сервер --VLESS+Reality+XHTTP--> зарубежный сервер --> интернет
```

Российские сайты открываются напрямую с RU-сервера, всё остальное идёт через зарубежный.

## Что нужно

- Два сервера с Ubuntu 22.04 или 24.04 и доступом root: российский и зарубежный.
- SSH-доступ к российскому серверу (например, из Termius на телефоне).
- Root-пароль зарубежного сервера. Скрипт спросит его один раз, чтобы скопировать туда SSH-ключ.

## Установка

Зайти по SSH на **российский** сервер и выполнить:

```bash
wget -O /usr/local/bin/cascade https://raw.githubusercontent.com/vitalydze/cascade/main/cascade.sh
chmod +x /usr/local/bin/cascade
cascade install <IP зарубежного сервера>
```

Скрипт сам зайдёт на зарубежный сервер и настроит его. В конце он проверит, что всё работает.
На зарубежный сервер ходить руками не нужно.

## Команды

| Команда | Что делает |
|---|---|
| `cascade add iphone` | новый клиент: создаёт `/root/cascade/iphone.conf` и показывает QR-код |
| `cascade del iphone` | удаляет клиента |
| `cascade list` | список клиентов и когда они подключались |
| `cascade status` | состояние служб и список клиентов |
| `cascade test` | проверяет, что трафик идёт через зарубежный сервер |
| `cascade install <IP>` | повторная настройка или переезд на новый зарубежный сервер (ключи и клиенты сохраняются) |

## Как загрузить конфиг на устройство

**Телефон, через Termius.** Открой SFTP к российскому серверу и зайди в папку `/root/cascade/`.
Скачай оттуда `iphone.conf` в «Файлы». Затем в приложении WireGuard выбери «+» → «Создать из файла или архива».

**Через QR-код.** Команда `cascade add` сразу показывает QR-код. Его можно отсканировать приложением WireGuard с экрана другого устройства.
Показать QR-код ещё раз: `qrencode -t ansiutf8 < /root/cascade/iphone.conf`

**Компьютер с Linux.** Скачай конфиг:

```bash
scp root@<IP RU>:/root/cascade/laptop.conf .
```

Потом установи его и включи туннель:

```bash
sudo cp laptop.conf /etc/wireguard/cascade.conf
```

```bash
sudo systemctl start wg-quick@cascade
```

Выключить: `sudo systemctl stop wg-quick@cascade`.

Если wg-quick ругается на resolvconf (в Ubuntu его по умолчанию нет или стоит старый пакет),
один раз выполни:
  sudo apt purge -y resolvconf
  sudo ln -s /usr/bin/resolvectl /usr/local/sbin/resolvconf

## Если перестало работать

1. На RU-сервере выполни `cascade test`.
2. Если тест не проходит, выполни `cascade install <IP>` ещё раз. Ключи сохранятся, клиентам ничего менять не нужно.
3. Если не помогло, попробуй другой сайт для маскировки. Поменяй `SNI=` в начале `/usr/local/bin/cascade`
   (например, на `www.samsung.com` или `dl.google.com`) и снова выполни `cascade install <IP>`.

## Почему XHTTP, а не обычный VLESS+Reality (TCP+vision)

С TCP+vision каждое соединение пользователя открывает отдельное TLS-соединение до зарубежного сервера.
Телефон или браузер открывают десятки соединений сразу. На такое количество ТСПУ реагирует тем, что начинает
отбрасывать хендшейки, и на несколько минут перестаёт работать всё.
XHTTP пропускает много потоков через несколько долгоживущих соединений: 100 параллельных запросов идут всего через ~6 соединений.

## Где что лежит (на RU-сервере)

- `/etc/cascade/env` — все ключи и настройки
- `/root/cascade/*.conf` — конфиги клиентов
- `/etc/wireguard/wg0.conf` — собирается скриптом автоматически, руками не править
- `/usr/local/etc/xray/config.json` — конфиг Xray (на зарубежном сервере по тому же пути)
